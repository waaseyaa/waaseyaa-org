This site now pins Waaseyaa Framework and its directly required packages to
alpha.305. The documentation corpus is regenerated from that exact release.

The framework release includes explicit HTTP handler bindings and route metadata
admission for API, authentication, MCP and SSR surfaces. These changes preserve
existing request behavior while separating route inspection from handler creation.

Waaseyaa remains alpha software. This release note describes the site's selected
framework version and does not certify every framework capability for production.
