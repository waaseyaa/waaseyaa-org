This site now runs Waaseyaa v0.1.0-alpha.285, upgraded from alpha.276.

The intervening releases add the first content-publishing package, enforce MCP
tool input schemas, and correct anonymous stateless-session path matching. They
also introduce manifest-backed and attribute-selectable SQL field storage,
including indexed fields and fixes for physical and reserved-word columns.
Request query parameters now reach `RequestContext`, and schema scanner output
uses canonical column names with enforced scanner-version validation.

Waaseyaa remains alpha software. The site continues to keep its three
git-published proof-engine entity types off JSON:API while the anonymous
published-read transport issue is tracked upstream.
