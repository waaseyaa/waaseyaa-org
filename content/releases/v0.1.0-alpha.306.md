This site pins Waaseyaa Framework and its directly required packages to
alpha.306. Its documentation corpus is regenerated from that exact release.

The framework release includes fixes for authenticated messaging membership,
authorized generated-application owners on the admin surface, and listing filter
semantics. It also strengthens audit and boot-query handling under SQLite
contention.

The site's getting-started guide now includes every Todo application file,
the required site and installation lifecycle, and a permission-based access
policy. Its verifier extracts the displayed examples into a fresh published
starter and checks create, list, both toggle directions, persistence, deletion
and anonymous access refusal through HTTP.

Waaseyaa remains alpha software. This release note describes the site's selected
framework version and does not certify every framework capability for production.
