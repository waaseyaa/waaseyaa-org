This site pins Waaseyaa Framework and its directly required packages to
alpha.307. The documentation corpus is regenerated from that exact release.

Framework alpha.307 preserves generated site verification across Windows Git
checkouts with a portable PHP-invoked verifier that does not depend on the
executable bit. The getting-started guide now uses a fresh alpha.307 project
without a chmod or Git index-mode workaround. Existing alpha.306 applications
need the [reviewed regeneration procedure](https://github.com/waaseyaa/framework/blob/v0.1.0-alpha.307/docs/upgrade-notes/site-generated-verification-portability.md)
to adopt this fix.

Waaseyaa remains alpha software. This note describes the selected framework
release and does not certify every framework capability for production.
