# Support

- Framework documentation: https://waaseyaa.org/docs (also as Markdown and
  over MCP; see https://waaseyaa.org/llms.txt)
- Getting started: https://waaseyaa.org/start
- Questions and bug reports about this site: open an issue in this
  repository.
- Questions and bug reports about the framework: open an issue at
  https://github.com/waaseyaa/framework.
- Security reports: see SECURITY.md; do not open public issues.

There is no commercial support offering. The framework is alpha software
in production use at First Nations Procurement Inc.
